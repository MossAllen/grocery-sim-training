# 🏪 ร้านชำจำลอง — Marketing Training Lab

เกมฝึกจำลองสถานการณ์จริง เตรียมเข้า ปวส. การตลาด แปลงจาก **แผนฝึกการตลาด 8 สัปดาห์.docx** ให้เล่นได้บนเบราว์เซอร์
8 สัปดาห์ × 5 รอบ = 40 รอบ + แบบทดสอบท้ายแผน ทุกรอบมี 📖 ทฤษฎี → 🛠️ ลงมือทำ → ✅ ตรวจผล ตามโครงในเอกสาร

## เล่นเกม

```powershell
python -m http.server 8765 --directory game
```

แล้วเปิด <http://localhost:8765> (หรือดับเบิลคลิก `game/index.html` ก็เล่นได้ แต่เสียงไฟล์จริงอาจไม่โหลด)

ไม่ต้องติดตั้งอะไรเพิ่ม เป็น HTML/CSS/JavaScript ล้วน ความคืบหน้าบันทึกในเบราว์เซอร์ (localStorage)

## มีอะไรในเกม

| กลไก | ใช้ในรอบ | สิ่งที่ผู้เล่นทำ |
|---|---|---|
| ฉากร้าน (observe) | ส.1 ร.2 | คลิกลูกค้าที่มี ❗ จดข้อสังเกต 5 ครั้ง แล้วแยก "ข้อสังเกต" กับ "การตีความ" |
| จำลองโปร (sim) | ส.4 ร.1–3 | วัดยอดปกติ 30 นาที → ตั้งราคาโปร คำนวณจุดคุ้มทุน → ทดลองจริงในฉาก → ตัดสินใจ ทำต่อ/ปรับ/หยุด |
| โจทย์ตัวเลข (calc) | งบเงิน ราคาต่อหน่วย ผ่อน กำไร สต็อก อัตราทัก ลงทุน ค่าเงิน | ตัวเลขสุ่มใหม่ทุกครั้ง 🎲 พร้อมวิธีคิด |
| บทสนทนาอังกฤษ (dialogue) | รอบที่ 4 ทุกสัปดาห์ + ส.7 | เลือกประโยคถูก ฟังเสียงพูด 🔊 ฟังตัวเลข ทอนเงิน |
| จัดกลุ่ม (sort) | 4P กลุ่มลูกค้า เส้นทางลูกค้า BMC สไลด์ | คลิกการ์ดแล้ววางในกล่อง |
| สร้างโพสต์ (post) | ส.5 ร.2 | เลือกส่วนประกอบโพสต์ ทดสอบกับผู้ชมจำลอง → ใช้ตัวเลขในรอบถัดไป |
| นำเสนอ (pitch) | ส.8 ร.4 | บทพูด 60 วินาทีสร้างจากผลทดลองของผู้เล่น จับเวลา อัดเสียง ประเมินตัวเอง |
| แฟ้มผลงาน | ทุกรอบ | ดาวน์โหลดชิ้นงานทั้งหมดเป็น `.md` |
| เกณฑ์ 5 ด้าน | หน้าแผนที่ | ตัวเลข · หลักฐาน · เหตุผล · ภาษาอังกฤษ · ชิ้นงาน (0–2 คะแนน เป้าหมาย ≥ 8/10) |

## ทีมและการส่งต่องาน

| บทบาท | ผู้รับผิดชอบ | ไฟล์ที่เป็นเจ้าของ |
|---|---|---|
| แบบแผนและแนวคิดเกม | **ChatGPT SOL** | `docs/GDD.md` |
| โค้ดคำสั่งสร้างเกม | **Claude Opus** | `game/js/`, `game/css/`, `game/index.html` |
| เสียงเอฟเฟกต์และรายละเอียดในเกม | **Gemini Neo** | `docs/AUDIO_SPEC.md`, `game/assets/audio/` |
| ภาพ/โมเดล 3D | **Blender** | `blender/`, `game/assets/sprites/`, `docs/ART_SPEC.md` |
| ส่งข้อมูลและส่งต่องาน | **GitHub** | `.github/`, `handoff/` |

อ่านขั้นตอนละเอียดที่ **[docs/HANDOFF.md](docs/HANDOFF.md)** — มี branch, ใบส่งต่องาน, checklist และ prompt สำเร็จรูปของแต่ละ AI

## โครงสร้างโฟลเดอร์

```
marketing-training-lab/
├─ แผนฝึกการตลาด 8 สัปดาห์.docx   ← เอกสารต้นฉบับ (แหล่งความจริงของเนื้อหา)
├─ game/                           ← ตัวเกม (เปิด index.html)
│  ├─ js/curriculum.js             ← เนื้อหา 40 รอบ (แก้เนื้อหาที่นี่)
│  ├─ js/engines.js                ← กลไกเล่นแต่ละแบบ
│  ├─ js/store-scene.js            ← ฉากร้านบน canvas
│  ├─ assets/audio/manifest.js     ← Gemini ใส่ไฟล์เสียง
│  └─ assets/sprites/manifest.js   ← Blender เขียนทับอัตโนมัติ
├─ blender/generate_store_assets.py
├─ docs/  GDD · HANDOFF · AUDIO_SPEC · ART_SPEC
├─ handoff/                        ← ใบส่งต่องานแต่ละรอบ
└─ .github/                        ← template PR/issue + deploy GitHub Pages
```

## สร้างภาพใหม่จาก Blender

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.3\blender.exe" -b -P blender/generate_store_assets.py
```

> ตัวเลขยอดขาย ผลโพสต์ และผลโปรในเกมเป็น **ข้อมูลจำลอง** ให้ผู้ฝึกกำกับในใบงานเสมอว่าข้อมูลใดจริง ข้อมูลใดจำลอง ตามที่เอกสารต้นฉบับกำหนด
