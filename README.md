# 🏪 ร้านชำจำลอง — Marketing Training Lab

เกมฝึกจำลองสถานการณ์จริง เตรียมเข้า ปวส. การตลาด แปลงจาก **แผนฝึกการตลาด 8 สัปดาห์.docx** ให้เล่นได้บนเบราว์เซอร์
8 สัปดาห์ × 5 รอบ = 40 รอบ + แบบทดสอบท้ายแผน ทุกรอบมี 📖 ทฤษฎี → 🛠️ ลงมือทำ → ✅ ตรวจผล ตามโครงในเอกสาร

## เล่นเกม

🎮 **เล่นออนไลน์:** <https://mossallen.github.io/grocery-sim-training/>  ·  📂 **Repo:** <https://github.com/MossAllen/grocery-sim-training>

หรือรันในเครื่อง:

```powershell
python tools/serve-preview.py
```

เปิดหน้าเกมที่ <http://127.0.0.1:8787/> หรือเข้าฉากตรงที่ [เดินสังเกตลูกค้า](http://127.0.0.1:8787/#observe-walk) และ [เดินเทียบราคา](http://127.0.0.1:8787/#shelf-walk)

เกมใช้ HTML/CSS/JavaScript และบันทึกความคืบหน้าในเบราว์เซอร์ รุ่นพรีวิวรองรับติดตั้งบนหน้าจอโฮมและเตรียมบทเรียนกับฉากเดินไว้เล่นออฟไลน์ ดูวิธีติดตั้งจากเว็บ HTTPS และขั้นตรวจบนมือถือใน [คู่มือเล่นและตรวจรับ](handoff/2026-11-28_walk-preview-acceptance.md)

## มีอะไรในเกม

| กลไก | ใช้ในรอบ | สิ่งที่ผู้เล่นทำ |
|---|---|---|
| ฉากร้าน (observe) | ส.1 ร.2 | จดข้อสังเกต 5 ครั้งและแยกสิ่งที่เห็นจากการตีความ เลือกฉากเทียบเช้า–เย็นเพื่อดูจำนวนและตัวหารของแต่ละช่วงได้ |
| ทดลองโปร (sim) | ส.4 ร.1–4 | เลือกเล่นแบบจำลองหรือใช้ข้อมูลร้าน บันทึกยอดปกติ → ตั้งราคาโปร → กรอกผลที่วัดได้หรือคำนวณผลคาดการณ์ → ใช้ราคาของชุดนั้นฝึกพูด |
| โจทย์ตัวเลข (calc) | งบเงิน ราคาต่อหน่วย ผ่อน กำไร สต็อก อัตราทัก ลงทุน ค่าเงิน | ตัวเลขสุ่มใหม่ทุกครั้ง 🎲 พร้อมวิธีคิด |
| บทสนทนาอังกฤษ (dialogue) | รอบที่ 4 ทุกสัปดาห์ + ส.7 | เลือกประโยค ฟังเสียง Ogg ของประโยคหลัก และใช้เสียงอ่านของเบราว์เซอร์กับตัวเลขที่เปลี่ยนตามโจทย์ |
| จัดกลุ่ม (sort) | 4P กลุ่มลูกค้า เส้นทางลูกค้า BMC สไลด์ | คลิกการ์ดแล้ววางในกล่อง |
| สร้างโพสต์ (post) | ส.5 ร.2 | เลือกส่วนประกอบโพสต์ ทดสอบกับผู้ชมจำลอง → ใช้ตัวเลขในรอบถัดไป |
| นำเสนอ (pitch) | ส.8 ร.4 | บทพูด 60 วินาทีสร้างจากผลทดลองของผู้เล่น จับเวลา อัดเสียง ประเมินตัวเอง |
| แฟ้มผลงาน | ทุกรอบ | ดาวน์โหลดชิ้นงานทั้งหมดเป็น `.md` |
| เกณฑ์ 5 ด้าน | หน้าแผนที่ | ตัวเลข · หลักฐาน · เหตุผล · ภาษาอังกฤษ · ชิ้นงาน (0–2 คะแนน เป้าหมาย ≥ 8/10) |

โหมดข้อมูลร้านเก็บในเบราว์เซอร์แยกตามกลุ่มสินค้า ใช้กับใบงานสต็อก 5 รายการ (ส.3) การทดลองโปร (ส.4) และอัตราทักและสั่ง (ส.5 ร.3) ส.8 ร.2 แสดงหลักฐานที่ยังอ้างอิงได้พร้อมปุ่มกลับไปรอบต้นทาง ลบข้อมูลร้านของสินค้าที่เลือกได้จาก **ตั้งค่า** โดยเก็บดาวไว้

## โครงสร้างโฟลเดอร์

```
marketing-training-lab/
├─ แผนฝึกการตลาด 8 สัปดาห์.docx   ← เอกสารต้นฉบับ (แหล่งความจริงของเนื้อหา)
├─ game/                           ← ตัวเกม (เปิด index.html)
│  ├─ js/curriculum.js             ← เนื้อหา 40 รอบ (แก้เนื้อหาที่นี่)
│  ├─ js/engines.js                ← กลไกเล่นแต่ละแบบ
│  ├─ js/store-scene.js            ← ฉากร้านบน canvas
│  ├─ assets/audio/manifest.js     ← Gemini ใส่ไฟล์เสียง
│  └─ assets/sprites/manifest.js   ← คีย์ภาพที่เกมโหลด
├─ blender/generate_stud_sprites.py
├─ docs/  GDD · HANDOFF · AUDIO_SPEC · ART_SPEC · RESEARCH · ROADMAP
├─ handoff/                        ← ใบส่งต่องานแต่ละรอบ
└─ .github/                        ← template PR/issue + deploy GitHub Pages
```
