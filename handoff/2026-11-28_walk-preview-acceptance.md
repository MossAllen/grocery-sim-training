# เปิดเล่น ตรวจรับ และส่งต่องานฉากเดิน

ฉบับพรีวิว `0.5.6-preview` อยู่ใน `feat/shelf-walk-preview` โค้ดเกมที่ตรวจเริ่มจาก `289c517` เว็บที่เผยแพร่อยู่เป็น v0.4 ให้ใช้พรีวิวในเครื่องสำหรับ W1R2 และ W2R2 รุ่นนี้

## เปิดเกมจากเครื่องหรือมือถือ

ในเครื่อง Windows เปิด PowerShell ที่โฟลเดอร์โครงการแล้วรัน

```powershell
python -m http.server 8787 --bind 127.0.0.1 --directory game
```

- [W1R2 เดินสังเกตลูกค้า](http://127.0.0.1:8787/#observe-walk)
- [W2R2 เดินเทียบราคาและจ่ายเงิน](http://127.0.0.1:8787/#shelf-walk)

สำหรับมือถือ ให้ต่อ Wi‑Fi เดียวกับคอม เปลี่ยน `127.0.0.1` ในคำสั่งเป็น IPv4 ของ Wi‑Fi ที่ดูจาก `ipconfig` แล้วเปิดสองลิงก์ด้านบนโดยเปลี่ยนเลข IP ให้ตรงกัน ใช้ `Ctrl+C` ในหน้าต่าง PowerShell เพื่อปิดพรีวิว

## เล่นและตรวจผลด้วยตัวเอง

เปิดแท็บส่วนตัวหากต้องการเริ่มจากเซฟว่างโดยเก็บเซฟเดิมไว้ เลือก **น้ำดื่ม** แล้วกด **เข้าร้าน** ใช้ปุ่มลูกศรบนจอเพื่อเดินและหัน หรือใช้ WASD / ลูกศร, Q/R และ E บนคอม

### W1R2 เดินสังเกตลูกค้า

1. เดินเข้าใกล้และหันหาลูกค้าจนคำบรรยายแสดงสิ่งที่เห็นและได้ยิน กด **จดลงสมุด** ช่วงเช้ามี 07:02, 07:06 และ 07:09 กด **ไปช่วงเย็น** แล้วจด 17:04 และ 17:08 หากหาตำแหน่งลูกค้าไม่เจอ ใช้ปุ่ม **ไปหาลูกค้า** ในรายการใต้ฉาก
2. ลองกดฟังซ้ำแล้วกดปุ่มจดอีกครั้ง สมุดควรมีหนึ่งแถวต่อเหตุการณ์ รวม 5 แถวตามลำดับเวลา และข้อความยืนยันการจดควรอยู่ให้เห็น
3. กด **ไปวิเคราะห์ในสมุด** แยกสิ่งที่สังเกตได้จากเหตุผลที่ตีความ จับคู่หลักฐานให้ครบ และเทียบช่วงเช้า **ซื้อเร็วหรือพกพา 2/3 คน** กับช่วงเย็น **ซื้อไว้ใช้ที่บ้าน 2/2 คน**
4. เลือกข้อเสนอจากหลักฐาน เช่น ใช้เหตุการณ์ 07:06 เสนอเปิดช่องจ่ายเร็วสำหรับลูกค้าที่ซื้อชิ้นเดียวช่วงเช้า แล้วบันทึก ตรวจผลในหน้าสรุปและแฟ้มผลงาน ตอบถูกครบได้ 12/12 และ 3 ดาว

### W2R2 เดินเทียบราคาและจ่ายเงิน

1. อ่านป้าย A แล้วเดินขวาไปอ่าน B สำหรับน้ำดื่มชุดแรก A คือ 12 บาท / 600 มล. = **20.00 บาท/ลิตร** ส่วน B คือ 20 บาท / 1.5 ลิตร = **13.33 บาท/ลิตร** หยิบแพ็ก **B** แล้วเดินต่อถึงเคาน์เตอร์
2. กรอกราคาต่อหน่วยทั้งสองค่า กดวางแพ็กบนเครื่องสแกน ยอดรวมควรเป็น **20 บาท** และใบเสร็จมีหนึ่งรายการ กดสแกนซ้ำเพื่อตรวจข้อความแจ้งเตือนและจำนวนรายการ
3. เลือกเงิน 20 และ 5 บาท กดจ่าย แล้วกรอกเงินทอน **5 บาท** บันทึกผลและตรวจใบเสร็จรวม 20 บาท รับ 25 บาท ทอน 5 บาท งบเหลือ 5 บาท และได้ 3/3 เมื่อเทียบราคากับเลือกแพ็กถูก
4. กดเล่นอีกครั้งเพื่อตรวจว่าป้ายเปลี่ยนเป็น A **15.00 บาท/ลิตร** และ B **16.00 บาท/ลิตร** ชุดนี้แพ็ก A คุ้มกว่า

## ผลบนมือถือจริงที่ส่งให้ Claude

ก่อนส่งต่อ ตรวจทั้งสองลิงก์ด้วย Chromium จากเซฟว่างตามตัวอย่างน้ำดื่มและบันทึกผลได้ 3 ดาวทั้งสองฉาก กรณีจำลองจอสัมผัส 320×568 ที่เปิดการเคลื่อนไหวผ่านการเล่นทั้งสองฉากและการกดเดินค้าง

เล่นทั้งสองฉากจนจบบนมือถือเครื่องเดียว ลองแตะปุ่มเดิน กดเดินค้าง และลากเพื่อหัน ตรวจว่าปุ่มจดพ้นแถบบน คำบรรยายอ่านทัน เห็นหน้าและของที่ลูกค้าถือ และการเดินลื่น ใน W2R2 ให้เช็กว่าคีย์บอร์ดมือถือเปิดแล้วกรอกตัวเลขและกดขั้นถัดไปได้ ถ้าเปิดเสียงให้ลองฟังจังหวะก้าว จด หยิบ สแกน และรับเงินทอน

ส่งผลโดยระบุ **รุ่นมือถือ ระบบปฏิบัติการ เบราว์เซอร์ ฉากและขั้นที่ทดสอบ ผลที่เห็น** ถ้าติดขัดให้เพิ่มผลที่คาดหวังและภาพหน้าจอถ้ามี รายงานได้หลังบันทึกผลทั้งสองฉากครบ

## รันชุดตรวจซ้ำบน Windows

ใช้ Node.js 24 ตาม [GitHub Actions](../.github/workflows/pages.yml) รันจากโฟลเดอร์โครงการ

```powershell
node tools/check.js
$auditDir = Join-Path ([System.IO.Path]::GetTempPath()) 'grocery-preview-audit'
npm install --prefix $auditDir --no-save --ignore-scripts --no-audit --no-fund playwright@1.62.0 axe-core@4.14.1 lighthouse@13.6.0
$modules = Join-Path $auditDir 'node_modules'
& (Join-Path $modules '.bin/playwright.cmd') install chromium
node tools/run-browser-check.js $modules
```

หากมี Playwright, axe-core, Lighthouse และ Chromium ติดตั้งอยู่แล้ว ให้ส่งพาธ `node_modules` ที่มีอยู่เข้า `tools/run-browser-check.js` ได้เลย ผลที่คาดไว้คือ `check.js` ผ่าน 14,031 รายการ และชุด Chromium ผ่านบทเรียนและคำถามเช็ก 240 ชุด เซฟรอบ 120 ครั้ง เซฟประเมินท้ายเกม 3 ครั้ง ฉากเดินทั้งสองสำหรับสามกลุ่มสินค้า และโหมดข้อมูลร้าน ผล axe และ Lighthouse แสดงท้ายชุดตรวจ ชุด Chromium และขนาดจอจำลองใช้ตรวจพฤติกรรมซ้ำได้ ส่วนสัมผัส เสียง และความลื่นบนเครื่องจริงบันทึกเป็นผลตรวจอีกครั้งจากมือถือ
