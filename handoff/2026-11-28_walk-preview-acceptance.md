# เปิดเล่น ตรวจรับ และส่งต่องานฉากเดิน

ฉบับพรีวิว `0.6.1-preview` อยู่ใน `feat/shelf-walk-preview` มีหน้าเลือกสินค้าและแผนที่ใหม่ เอฟเฟกต์ฉากเดิน และเว็บแอปสำหรับเปิดจากไอคอนหน้าจอโฮม เว็บที่เผยแพร่อยู่เป็น v0.4 ให้ใช้พรีวิวในเครื่องสำหรับเล่นและตรวจรุ่นนี้

## เปิดเกมจากเครื่องหรือมือถือ

ในเครื่อง Windows เปิด PowerShell ที่โฟลเดอร์โครงการแล้วรัน

```powershell
python tools/serve-preview.py
```

- [W1R2 เดินสังเกตลูกค้า](http://127.0.0.1:8787/#observe-walk)
- [W2R2 เดินเทียบราคาและจ่ายเงิน](http://127.0.0.1:8787/#shelf-walk)

สำหรับมือถือ ให้ต่อ Wi‑Fi เดียวกับคอม ดู IPv4 ของ Wi‑Fi จาก `ipconfig` จากนั้นรัน `python tools/serve-preview.py --bind 192.168.1.130` โดยแทนเลขตัวอย่างด้วย IP ของคอม แล้วเปิดลิงก์ที่พิมพ์ในหน้าต่าง PowerShell ใช้ `Ctrl+C` เพื่อปิดพรีวิว

## ติดตั้งบนโทรศัพท์หรือ iPad

ใช้พรีวิว Wi‑Fi สำหรับลองเล่น เปิดเว็บรุ่น `0.6.1-preview` ผ่าน **HTTPS** เมื่อต้องการติดตั้งจากมือถือ สำหรับทดสอบการเตรียมออฟไลน์จากคอม ใช้ `http://127.0.0.1:8787/` ได้ [การติดตั้ง PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

1. **iPhone และ iPad** เปิดเกมใน Safari แตะ **แชร์ → เพิ่มไปยังหน้าจอโฮม** เปิด **เปิดเป็นเว็บแอป** หากแสดง แล้วแตะ **เพิ่ม** [คู่มือ iPad](https://support.apple.com/en-gb/guide/ipad/ipad8f1f7a29/27/ipados/27) · [คู่มือ iPhone](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/27/ios/27)
2. **Android** เปิดเกมใน Chrome แตะ **วิธีติดตั้งเกม → ติดตั้งเกม** เมื่อปุ่มปรากฏ หรือเลือก **ติดตั้งและสร้างทางลัด → ติดตั้ง** จากเมนู Chrome [คู่มือ Chrome สำหรับ Android](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=en)
3. เปิดไอคอนร้านชำจำลองครั้งแรกขณะออนไลน์ แตะ **ติดตั้งและเล่นออฟไลน์** แล้วรอข้อความ **พร้อมเล่นบทเรียนและฉากเดินออฟไลน์** เมื่อพร้อมให้เปิดโหมดเครื่องบิน เปิดแอปอีกครั้ง และลองเปิดบทเรียนกับฉากเดิน ลิงก์อ่านประกอบภายนอกใช้เน็ต
4. เมื่อติดตั้งแล้วให้ทดสอบ iPad ทั้งแนวตั้งและแนวนอน ลองพิมพ์ราคาและเงินทอนขณะคีย์บอร์ดเปิด แล้วบันทึกและเปิดใหม่ เซฟของพรีวิว Wi‑Fi และเว็บที่เผยแพร่เก็บแยกตามที่อยู่เว็บ

หากเกมแจ้งว่ามีรุ่นใหม่ ให้บันทึกผลและปิดหน้าต่างเกมทุกหน้าก่อนเปิดไอคอนอีกครั้ง เพื่อให้หน้าเดิมเล่นต่อด้วยไฟล์รุ่นเดียวจนจบรอบ

## เล่นและตรวจผลด้วยตัวเอง

เปิดแท็บส่วนตัวหากต้องการเริ่มจากเซฟว่างโดยเก็บเซฟเดิมไว้ เลือก **น้ำดื่ม** แล้วกด **เข้าร้าน** ใช้ปุ่มลูกศรบนจอเพื่อเดินและหัน หรือใช้ WASD / ลูกศร, Q/R และ E บนคอม

### W1R2 เดินสังเกตลูกค้า

1. เดินเข้าใกล้และหันหาลูกค้าจนคำบรรยายแสดงสิ่งที่เห็นและได้ยิน กด **จดลงสมุด** ช่วงเช้ามี 07:02, 07:06 และ 07:09 กด **ไปช่วงเย็น** แล้วจด 17:04 และ 17:08 หากหาตำแหน่งลูกค้าไม่เจอ ใช้ปุ่ม **ไปหาลูกค้า** ในรายการใต้ฉาก
2. เมื่อจดสำเร็จให้ดูเครื่องหมายและแถบความคืบหน้า ลองกดฟังซ้ำแล้วกดปุ่มจดอีกครั้ง สมุดควรมีหนึ่งแถวต่อเหตุการณ์ รวม 5 แถวตามลำดับเวลา และข้อความยืนยันการจดควรอยู่ให้เห็น
3. กด **ไปวิเคราะห์ในสมุด** แยกสิ่งที่สังเกตได้จากเหตุผลที่ตีความ จับคู่หลักฐานให้ครบ และเทียบช่วงเช้า **ซื้อเร็วหรือพกพา 2/3 คน** กับช่วงเย็น **ซื้อไว้ใช้ที่บ้าน 2/2 คน**
4. เลือกข้อเสนอจากหลักฐาน เช่น ใช้เหตุการณ์ 07:06 เสนอเปิดช่องจ่ายเร็วสำหรับลูกค้าที่ซื้อชิ้นเดียวช่วงเช้า แล้วบันทึก ตรวจผลในหน้าสรุปและแฟ้มผลงาน ตอบถูกครบได้ 12/12 และ 3 ดาว

### W2R2 เดินเทียบราคาและจ่ายเงิน

1. อ่านป้าย A แล้วเดินขวาไปอ่าน B สำหรับน้ำดื่มชุดแรก A คือ 12 บาท / 600 มล. = **20.00 บาท/ลิตร** ส่วน B คือ 20 บาท / 1.5 ลิตร = **13.33 บาท/ลิตร** หยิบแพ็ก **B** แล้วเดินต่อถึงเคาน์เตอร์
2. กรอกราคาต่อหน่วยทั้งสองค่า กดวางแพ็กบนเครื่องสแกน ดูแพ็กย้ายจากมือไปที่แท่นและแสงสแกนหนึ่งครั้ง ยอดรวมควรเป็น **20 บาท** และใบเสร็จมีหนึ่งรายการ กดสแกนซ้ำเพื่อตรวจข้อความแจ้งเตือนและจำนวนรายการ
3. เลือกเงิน 20 และ 5 บาท กดจ่าย แล้วกรอกเงินทอน **5 บาท** บันทึกผลและตรวจใบเสร็จรวม 20 บาท รับ 25 บาท ทอน 5 บาท งบเหลือ 5 บาท และได้ 3/3 เมื่อเทียบราคากับเลือกแพ็กถูก
4. กดเล่นอีกครั้งเพื่อตรวจว่าป้ายเปลี่ยนเป็น A **15.00 บาท/ลิตร** และ B **16.00 บาท/ลิตร** ชุดนี้แพ็ก A คุ้มกว่า

## ผลบนมือถือจริงที่ส่งให้ Claude

รุ่น `0.6.1-preview` ผ่านฉากเดินทั้งสองบน Chromium และเปิดฉากเดินออฟไลน์บน Chromium กับ WebKit ที่จำลองจอ iPad แล้ว บนเครื่องจริงให้ลองการตอบสนองของเอฟเฟกต์ตอนจด หยิบ และสแกน รวมถึงเปิดเกมจากไอคอนที่ติดตั้งไว้หลังเปิดโหมดเครื่องบิน

เล่นทั้งสองฉากจนจบบนมือถือเครื่องเดียว ลองแตะปุ่มเดิน กดเดินค้าง และลากเพื่อหัน ตรวจว่าปุ่มจดพ้นแถบบน คำบรรยายอ่านทัน เห็นหน้าและของที่ลูกค้าถือ และการเดินลื่น ใน W2R2 ให้เช็กว่าคีย์บอร์ดมือถือเปิดแล้วกรอกตัวเลขและกดขั้นถัดไปได้ ถ้าเปิดเสียงให้ลองฟังจังหวะก้าว จด หยิบ สแกน และรับเงินทอน

ส่งผลโดยระบุ **รุ่นมือถือ ระบบปฏิบัติการ เบราว์เซอร์ ฉากและขั้นที่ทดสอบ ผลที่เห็น** ถ้าติดขัดให้เพิ่มผลที่คาดหวังและภาพหน้าจอถ้ามี รายงานได้หลังบันทึกผลทั้งสองฉากครบ

## รันชุดตรวจซ้ำบน Windows

ใช้ Node.js 24 ตาม [GitHub Actions](../.github/workflows/pages.yml) รันจากโฟลเดอร์โครงการ

```powershell
node tools/check.js
$auditDir = Join-Path ([System.IO.Path]::GetTempPath()) 'grocery-preview-audit'
npm install --prefix $auditDir --no-save --ignore-scripts --no-audit --no-fund playwright@1.62.0 axe-core@4.14.1 lighthouse@13.6.0
$modules = Join-Path $auditDir 'node_modules'
& (Join-Path $modules '.bin/playwright.cmd') install chromium
node tools/run-browser-check.js $modules
```

หากมี Playwright, axe-core, Lighthouse และ Chromium ติดตั้งอยู่แล้ว ให้ส่งพาธ `node_modules` ที่มีอยู่เข้า `tools/run-browser-check.js` ได้เลย ชุด Chromium ตรวจบทเรียนและคำถามเช็ก 240 ชุด เซฟรอบ 120 ครั้ง เซฟประเมินท้ายเกม 3 ครั้ง ฉากเดินทั้งสองสำหรับสามกลุ่มสินค้า และโหมดข้อมูลร้าน พร้อมตรวจ manifest และการเปิดเกมออฟไลน์จากพาธย่อยแบบ GitHub Pages ผล axe และ Lighthouse แสดงในชุดตรวจ
