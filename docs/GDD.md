# Game Design Document — ร้านชำจำลอง

> **เจ้าของเอกสาร: ChatGPT SOL** · ฉบับร่าง v0.1 เขียนโดย Claude Opus จากโค้ดที่ทำงานได้แล้ว เพื่อให้ ChatGPT ปรับแก้ต่อ
> แหล่งความจริงของเนื้อหา: `แผนฝึกการตลาด 8 สัปดาห์.docx`

## §1 แนวคิดหลัก

- **ประเภท:** เกมจำลองสถานการณ์ (simulation) + แบบฝึกหัด สำหรับผู้เตรียมเข้า ปวส. การตลาด
- **คำโปรย:** "เปิดร้านชำ สังเกตลูกค้า ทดลองโปร แล้วพิสูจน์ด้วยตัวเลข"
- **เป้าหมายผู้เล่น:** อธิบายได้ว่าเลือกขายให้ใคร ขายอย่างไร คุ้มหรือไม่ และใช้หลักฐานอะไรตัดสิน
- **แพลตฟอร์ม:** เบราว์เซอร์ (คอม/มือถือ) ไม่ต้องติดตั้ง
- **ระยะเวลา:** รอบละ ~10–17 นาทีในเกม (ส่วน "ลงมือทำ" ของคาบ 30 นาที) รวม 40 รอบ

## §2 วงจรการเล่น (Core Loop)

```
อ่านทฤษฎี (8 นาที) → เล่นรอบ: ลงมือ/จำลอง/คำนวณ (17 นาที) → ตรวจผล ดูวิธีคิด ได้ดาว (5 นาที)
      ↑                                                                          │
      └──────── เล่นซ้ำด้วยตัวเลขสุ่มใหม่ / ผลงานไหลไปรอบถัดไป ←─────────────────────┘
```

- **ผลงานไหลต่อกัน:** ยอดขายปกติ (ส.4 ร.1) → ใช้ในแผนโปร (ร.2) → ใช้ในการทดลอง (ร.3) → ใช้ในบทนำเสนอ (ส.8 ร.4) · ผลโพสต์ (ส.5 ร.2) → ใช้คำนวณอัตรา (ร.3) และตรวจซ้ำ (ส.8 ร.2)
- **เลือกสินค้าครั้งเดียวใช้ตลอดแผน:** น้ำดื่ม / ขนม / ของใช้ประจำวัน — เปลี่ยนชื่อสินค้า ราคา ขนาด และคำอังกฤษในทุกรอบ

## §3 กลไก (Engines)

| engine | คำอธิบาย | คะแนน (0–1 → ดาว) |
|---|---|---|
| `mcq` | คำถามตัวเลือก มีคำอธิบายหลังตอบ | ถูก/ทั้งหมด |
| `calc` | โจทย์ตัวเลขสุ่ม ตรวจทีละช่องพร้อมวิธีคิด กด 🎲 สุ่มใหม่ได้ | ช่องถูก/ทั้งหมด |
| `sort` | คลิกการ์ดแล้ววางลงกล่อง | วางถูก/ทั้งหมด |
| `dialogue` | ลูกค้าพูด (เสียง TTS) ผู้เล่นเลือกประโยคตอบ + ข้อฟังตัวเลข | ถูกครั้งแรก/ทั้งหมด |
| `observe` | ฉากร้าน ลูกค้าเดินเข้า คลิก ❗ เพื่อจด 5 เหตุการณ์ → เลือกการตีความ | ตีความถูก/5 |
| `sim` | `baseline` จำลอง 30 นาทีราคาปกติ · `plan` ตั้งราคาโปร+คำนวณ · `run` จำลองช่วงโปร+ตัดสินใจ | ตามโจทย์คำนวณ |
| `post` | เลือกส่วนประกอบโพสต์ ทดสอบกับผู้ชมจำลอง | คุณภาพโพสต์ |
| `pitch` | บทพูด 60 วินาทีจากผลของผู้เล่น จับเวลา 15/20/15/10 อัดเสียง ประเมินตัวเอง | เกณฑ์ที่ผ่าน/4 |

**ดาว:** 1.0 → ★★★ · ≥ 0.66 → ★★ · > 0 → ★ · 0 → ☆ (เก็บผลดีที่สุด)
**ปลดล็อก:** รอบถัดไปเปิดเมื่อเล่นรอบก่อนจบ · สัปดาห์ถัดไปเปิดเมื่อจบทุกรอบ · มี "โหมดครู" ปลดล็อกทั้งหมด

## §5 โมเดลจำลอง (ปรับสมดุลได้)

**ลูกค้าเข้าร้าน 30 นาที** (`engines.js → simulate`)
- จำนวนคน = สุ่ม 18–26 × (0.75 ถ้าฝนตก, โอกาส 25%) × (1 + 2 × ส่วนลดต่อชิ้น)
- โอกาสซื้อ: ปกติ 68% · มีป้ายโปร 78%
- ช่วงปกติ: ซื้อ 1 ชิ้น (80%) หรือ 2 ชิ้น (20%)
- ช่วงโปร: โอกาสเลือกชุดโปร = 0.12 + ส่วนลด × 3.2 (สูงสุด 85%) ซื้อ 2 ชุด 15%
- การตัดสินใจ: ผลหลังค่าป้าย ≥ ช่วงปกติ → ทำต่อ · > 0 → ปรับ · ≤ 0 → หยุด

**โพสต์** (`engines.js → post`)
- คุณภาพ q = (ส่วนที่ดี/6) − 0.2 × ส่วนที่ไม่ดี
- คนเห็น 150–320 · อัตราทัก ≈ 1% + 7% × q · อัตราสั่งในผู้ทัก ≈ 15% + 45% × q

## §6 เกณฑ์ประเมิน (หน้า 14 ของ docx)

แต่ละรอบผูกกับ 1 ด้าน: ตัวเลข · หลักฐาน · เหตุผล · ภาษาอังกฤษ · ชิ้นงาน
คะแนนด้าน = ค่าเฉลี่ยดาว ÷ 3 × 2 → รวม 10 คะแนน เป้าหมาย ≥ 8 และทุกด้าน ≥ 1

## §7 น้ำเสียงและภาพ

- สุภาพ เป็นกันเอง ภาษาไทยชัด ประโยคสั้น ใช้คำว่า "ลูกค้า" ไม่ใช้ชื่อคน
- ภาพ low-poly สีอบอุ่น ร้านชำไทย (ดู ART_SPEC) · เสียงสั้น นุ่ม ไม่ตกใจ (ดู AUDIO_SPEC)
- ทุกตัวเลขที่เกมสร้างต้องมีคำว่า "จำลอง" กำกับ

## §8 สิ่งที่ยังเปิดให้ ChatGPT SOL ออกแบบเพิ่ม

1. ฉากสังเกตแบบที่ 2: ลูกค้าแต่ละช่วงเวลา (เช้า/เย็น) มีพฤติกรรมต่างกัน ให้ผู้เล่นค้นพบกลุ่มลูกค้าเอง
2. โหมด "วันทำการ" ต่อเนื่อง: บริหารสต็อก+ราคา 5 วันในเกม แล้วอ่านงบ 3 ประเภทของร้านตัวเอง
3. ลูกค้าภาษาอังกฤษแบบพิมพ์ตอบอิสระ (ต้องการเกณฑ์ตรวจที่ไม่ใช้ AI)
4. ระบบเหรียญ/ตกแต่งร้านเป็นรางวัล — ต้องไม่ทำให้ผู้เล่นเดาสุ่มเพื่อเอารางวัล
5. ปรับสมดุล §5 จากผลเล่นทดสอบจริง
