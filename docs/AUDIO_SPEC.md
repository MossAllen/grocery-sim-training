# Audio Spec — เสียงเอฟเฟกต์และรายละเอียดในเกม

> **เจ้าของเอกสาร: Gemini Neo** · คีย์ในตารางรุ่น v0.4 ถูกเรียกจากโค้ดผ่าน `MTL.sfx.play('<key>')`
> เอฟเฟกต์ใช้พารามิเตอร์ ZzFX และมีเสียงสำรอง WebAudio ใน `game/js/sfx.js` เพลงฉากร้านใช้ไฟล์ Ogg

## วิธีส่งงาน

มี 2 ทางเลือก ต่อคีย์ (เลือกทางใดก็ได้):

- **ทาง A — ไฟล์เสียง:** วางไฟล์ใน `game/assets/audio/` ตั้งชื่อตามคีย์ เช่น `correct.ogg` แล้วแก้ `manifest.js` เป็น `"assets/audio/correct.ogg"`
- **ทาง B — ZzFX (แนะนำสำหรับ SFX สั้น):** ออกแบบเสียงที่ [ZzFX Designer](https://killedbyapixel.github.io/ZzFX/) กด Copy แล้ววางเฉพาะตัวเลขเป็น array ใน `manifest.js` เช่น `correct: [1,.05,523,0,.1,.2,1]` — ไม่มีไฟล์ ไม่มีปัญหาลิขสิทธิ์ (ใช้ไม่ได้กับ `bgm_store`)

ขั้นต่อไป:
1. รัน `node tools/check.js` เพื่อตรวจคีย์และไฟล์
2. ทดสอบในเกมตามขั้นด้านล่าง
3. เปิดเกม กด 🔊 ให้เปิดอยู่ แล้วเล่นรอบที่มีเสียงนั้น (ดูคอลัมน์ "ได้ยินที่")
4. ถ้าไฟล์โหลดไม่ได้ เกมจะกลับไปใช้เสียงสำรองเอง ไม่พัง

**มาตรฐานไฟล์:** `.ogg` (Vorbis) 44.1 kHz · SFX เป็น mono · peak ≤ −3 dBFS · ความดังใกล้เคียงกันทุกไฟล์ · ไม่เกิน 200 KB (เพลงไม่เกิน 1.5 MB) · ตัดเงียบหัวท้าย

## คิวเสียงต้นแบบฉากมุมมองบุคคลที่หนึ่ง

รอรับเสียงต้นฉบับจาก Gemini Neon ให้เชื่อมคีย์ใหม่เมื่อมีการตรวจไฟล์และผูกกับเหตุการณ์จริงในเกม

| คีย์ | จุดเล่นเสียงและการเล่นซ้ำ | เสียงสำรองเมื่อไฟล์ขาดหรือเล่นไม่ได้ |
|---|---|---|
| `step_shop` | ก้าวแรกเมื่อผู้เล่นเคลื่อนที่จริงบนพื้นร้าน แล้วเล่นทุกระยะก้าวขณะเดิน เว้นอย่างน้อย 0.42 วิ การยืน หมุนกล้อง และติดผนังใช้ภาพที่สอดคล้องกับตำแหน่งจริง | ใช้การเคลื่อนของภาพเป็นสัญญาณ |
| `shelf_pick` | เล่น 1 ครั้งเมื่อสินค้าย้ายจากชั้นเข้ามือสำเร็จ การวางแล้วหยิบใหม่ถือเป็นเหตุการณ์ใหม่ เว้นอย่างน้อย 0.20 วิ | `click` |
| `notebook` | เล่น 1 ครั้งเมื่อเพิ่มหลักฐานใหม่สำเร็จ โดยอ้างรหัสเหตุการณ์กับช่วงเวลา การเปิดสมุดและการลองจดหลักฐานเดิมแสดงสถานะบนจอ เว้นอย่างน้อย 0.20 วิ | `note` |
| `scanner` | เล่น 1 ครั้งต่อชิ้นเมื่อเคาน์เตอร์รับรหัสและเพิ่มรายการลงใบเสร็จ เว้นอย่างน้อย 0.25 วิ การสแกนที่ถูกปฏิเสธแสดงเหตุผลข้างรายการ | `click` |
| `cash_change` | เล่น 1 ครั้งเมื่อยืนยันการจ่ายเงินทอนในเกมจำลองได้สำเร็จและยอดเงินทอนมากกว่า 0 บาท ใช้รหัสธุรกรรมกันการเล่นซ้ำเมื่อกดซ้ำหรือเปิดใบเสร็จย้อนหลัง | `coin` |

- ใช้มาตรฐานไฟล์ข้างต้นและตั้ง peak ของ `step_shop` ราว −18 ถึง −12 dBFS และคิวตอบกลับราว −12 ถึง −6 dBFS ระหว่างเสียงพูดให้พักเสียงก้าว ลดเพลงและเสียงตอบกลับอย่างน้อย 6 dB และคืนระดับเมื่อประโยคจบ เสียงประกอบที่ข้ามไปจะจบในจังหวะนั้น
- ให้คีย์ใหม่เคารพ `State.data.settings.sound` และใช้เสียงสำรองเพียงครั้งเดียวต่อเหตุการณ์ แสดงข้อความคำพูดลูกค้า เวลา แถวหลักฐาน และสถานะใบเสร็จที่อ่านได้ขณะปิดเสียง ป้ายสถานะใกล้รายการต้องใช้ข้อความหรือไอคอนพร้อมคำอธิบาย
- ส่งไฟล์ต้นฉบับตามชื่อคีย์และแปลง WAV เป็น Ogg ก่อนเพิ่มใน manifest หรือส่งพารามิเตอร์ ZzFX/สคริปต์สร้างเสียงพร้อมวิธีรันและสิทธิ์ใช้งาน ทดสอบการเดินชน กดจดซ้ำ สแกนซ้ำ เปิดใบเสร็จย้อนหลัง ปิดเสียง และกรณีเสียงพูดซ้อนก่อนบันทึกผ่านเกณฑ์

## เสียงพูดภาษาอังกฤษ

บทสนทนาคงที่ 78 ประโยคใช้ไฟล์ `game/assets/voice/<id>.ogg` (Vorbis, mono, 44.1 kHz, ไม่เกิน 80 KB) สร้างด้วย FFmpeg + CMU Flite ใช้เสียงอเมริกัน `rms` สำหรับลูกค้าและ `slt` สำหรับพนักงาน ดูที่มาและเงื่อนไขใน `THIRD_PARTY.md`

เกมเทียบรหัสประโยคกับ `game/assets/voice/manifest.js` และใช้ Web Speech API (`en-US`, rate 0.92) กับข้อความที่เปลี่ยนตามข้อมูลผู้เล่น หรือเมื่อเปิดไฟล์เสียงไม่ได้ สร้างไฟล์และ manifest ซ้ำด้วย `node tools/voice_lines.js --audio` เมื่อ FFmpeg มีตัวกรอง `flite` และตัวเข้ารหัส `libvorbis`
