# Art Spec — ภาพและโมเดล 3D (Blender)

> **เจ้าของเอกสาร: ทีม Blender** · สคริปต์: `blender/generate_store_assets.py`
> เวอร์ชันปัจจุบัน v0.1 เป็นโมเดล low-poly พื้นฐานที่สร้างจากโค้ด ทดสอบแล้วกับ Blender 5.3 — ปรับให้สวยขึ้นได้โดยคงคีย์และขนาด

## วิธีสร้างภาพ

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.3\blender.exe" -b -P blender/generate_store_assets.py
```

สคริปต์จะ render PNG พื้นหลังโปร่งใสลง `game/assets/sprites/` และเขียนทับ `manifest.js` ให้อัตโนมัติ
ถ้าลบไฟล์ภาพหรือใส่ `null` เกมจะวาดด้วยอีโมจิแทน จึงไม่พัง

## รายการภาพ (ห้ามเปลี่ยนชื่อคีย์)

| คีย์ | ขนาด (px) | วาดในเกมที่ขนาด | คำอธิบาย |
|---|---|---|---|
| `shelf` | 260×180 | 130×90 | ชั้นวางไม้ 2 ชั้น มองหน้าตรง ไม่มีสินค้า (เกมวางสินค้าทับ) |
| `counter` | 320×160 | 160×80 | เคาน์เตอร์คิดเงิน + เครื่องเก็บเงิน |
| `customer_1` … `customer_5` | 88×132 | 56×84 | ลูกค้ายืนหันหน้า สีเสื้อต่างกัน ฐานเท้าอยู่ขอบล่าง |
| `item_water_small` / `item_water_big` | 48×56 | 24×28 | ขวดน้ำ 600 มล. / 1.5 ลิตร |
| `item_snack_small` / `item_snack_big` | 48×56 | 24×28 | ถุงขนมเล็ก / ใหญ่ |
| `item_household_small` / `item_household_big` | 48×56 | 24×28 | ทิชชู 1 ม้วน / แพ็ก 6 ม้วน |

## สไตล์

- low-poly สีอบอุ่น โทนร้านชำไทย (ไม้ ครีม ส้มอิฐ) แสงแดดเช้าจากซ้ายบน
- กล้อง orthographic เอียงลง 12° เล็งกลางวัตถุ เว้นขอบ ~18%
- ห้ามมีโลโก้หรือยี่ห้อจริงบนสินค้า
- ภาพต้องอ่านออกที่ขนาดเล็ก (24 px) — เน้นรูปทรงและสีมากกว่ารายละเอียด

## ขั้นต่อไปที่แนะนำ

1. ชั้นวางมีมุมมองด้านบนเล็กน้อยให้เห็นความลึก
2. ลูกค้า 2 ท่าทาง (ยืน/เดิน) → ถ้าต้องการ ให้ขอคีย์ `customer_<n>_walk` ผ่าน Issue ถึง Claude
3. ภาพพื้นหลังร้าน `store_bg` 800×380 (ต้องขอคีย์ใหม่ก่อน)
