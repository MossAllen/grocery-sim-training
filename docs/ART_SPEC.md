# Art Spec — ภาพและโมเดล 3D (Blender)

> **เจ้าของเอกสาร: ทีม Blender** · สคริปต์: `blender/generate_store_assets.py`
> โมเดล low-poly สร้างจากโค้ดและทดสอบกับ Blender 5.3 ใช้กล้องชุดเดียวกันสำหรับท่ายืนและท่าเดิน

ฉากเคาน์เตอร์สำหรับทดสอบแสง เอฟเฟกต์ และท่าทางใช้ `blender/build_checkout_preview.py` ดู [ช็อตและเกณฑ์ตรวจ](../handoff/to-blender.md) และ [สกิล Grocery Blender VFX](../.agents/skills/grocery-blender-vfx/SKILL.md) ส่วนตารางด้านล่างใช้กับสไปรต์ที่เกมโหลด

## วิธีสร้างภาพ

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.3\blender.exe" -b -P blender/generate_store_assets.py
```

สคริปต์จะ render PNG พื้นหลังโปร่งใสลง `game/assets/sprites/` และเขียนทับ `manifest.js` ให้อัตโนมัติ
ถ้าลบไฟล์ภาพหรือใส่ `null` เกมจะวาดด้วยอีโมจิแทน จึงไม่พัง

เติม `-- --walking-only` ท้ายคำสั่งเมื่อต้องการ render เฉพาะสี่ท่าเดินและอัปเดต manifest โดยเก็บไฟล์ภาพเดิมไว้ เกมสลับท่ายืนกับท่าเดินระหว่างที่ลูกค้าเคลื่อนที่และใช้ท่ายืนเมื่อพัก โหลดท่าเดินไม่ได้ หรืออุปกรณ์ตั้งให้ลดการเคลื่อนไหว

## สไตล์

- low-poly สีอบอุ่น โทนร้านชำไทย (ไม้ ครีม ส้มอิฐ) แสงแดดเช้าจากซ้ายบน
- กล้อง orthographic เอียงลง 12° เล็งกลางวัตถุ เว้นขอบ ~18%
- ห้ามมีโลโก้หรือยี่ห้อจริงบนสินค้า
- ภาพต้องอ่านออกที่ขนาดเล็ก (24 px) — เน้นรูปทรงและสีมากกว่ารายละเอียด

## ขั้นต่อไปที่แนะนำ

1. ชั้นวางมีมุมมองด้านบนเล็กน้อยให้เห็นความลึก
2. ภาพพื้นหลังร้าน `store_bg` 800×380 (ต้องขอคีย์ใหม่ก่อน)
